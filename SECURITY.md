# Security policy

A fix lands on `main` and in a patch release of the latest minor version.

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/tutti-audio/arc-lend/security/advisories/new),
not in a public issue. Include what is affected, how to reproduce it and what
it lets an attacker do.

A reader that can observe a freed value, a data race, or a read that waits,
allocates or frees is in scope.
